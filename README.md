# DaemonCraft

DaemonCraft is a branch of my preexisting web server project SpyderFly. You do not need SpyderFly installed to use DaemonCraft, it's just built off it. Working on DaemonCraft has solved issues with SpyderFly I was having. I'm taking DaemonCraft slowly. I will not give an estimated release date, because there's a good chance there will never be an official release.
AMP by Cubecoders was a big inspiration for me making parts of DaemonCraft. DaemonCraft is GNU, AMP is UNIX.
